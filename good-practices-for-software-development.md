# Good Practices for Software Development

## Question 1: Which point(s) were new to you?

- I learned that sending many small messages can disturb others.
- Keeping all questions together before messaging a teammate was new to me.
- Joining meetings 5–10 minutes early was a new point for me.
- I understood that this small habit can help me know my teammates better.
- I also learned that being available when someone replies can make work faster.

## Question 2: Which area do you think you need to improve on?

- I need to improve how I manage my time while working.
- I will first try to understand the problem and note down what I tried.
- I need to improve how I communicate when I face a problem.
- Then I will ask my teammate with the full details instead of just saying that something is not working.
- I will also take short breaks and do some exercise so I can stay focused
